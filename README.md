# LIFE IS MAX BET — 6ブランド Web施策比較

GitHub Pages用の静的サイトです。ビルドは不要です。

## 公開方法
1. GitHubで新規リポジトリを作成（例: `maxbet-web-strategy`）
2. このフォルダ内の `index.html`, `404.html`, `.nojekyll` をリポジトリ直下へアップロード
3. GitHubの **Settings → Pages** を開く
4. **Build and deployment → Source** を `Deploy from a branch` に設定
5. Branchを `main`、Folderを `/(root)` にして **Save**
6. 数分後、`https://<GitHubユーザー名>.github.io/maxbet-web-strategy/` で公開

## 更新
`index.html` を更新して main ブランチへ反映すると、GitHub Pages側も更新されます。
